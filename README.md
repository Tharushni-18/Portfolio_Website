Tharushni S.V. — Portfolio

A single-page, dark-mode personal portfolio showcasing my skills, internships, projects, education, certifications, and achievements. Built with plain **HTML, CSS, and JavaScript** — no frameworks, no build step.

Sections

- Home – introduction, social links, and resume download
- About– short bio and key stats
- Skills – technical skills, tools, and areas of interest
- Experience – internships (Prodigy InfoTech, Arttifai Tech)
- Projects– Code Documentation Generator, AI-Based Code Plagiarism Detector
- Education– B.Tech IT and Higher Secondary
- Certifications, Achievements, Extracurricular
- Contact – email, phone, and social profiles
